# Rootstock ERP Integration

## Description

Rootstock ERP is BBC's system of record for invoicing, fulfillment, and order status. When orders are placed in Salesforce B2B Commerce, they must be synchronized to Rootstock for fulfillment, invoicing, and financial reconciliation. Invoices are generated by Rootstock (not in Salesforce), and must be retrieved and displayed in order detail views. This integration is critical for order-to-cash workflows and co-op billing reporting.

## Current Implementation

**Integration Pattern:**
- MerchTank pushes order data to Rootstock
- Rootstock generates invoices
- Invoices are displayed/accessible in MerchTank

**Business Rules:**
- Orders flow from MerchTank → Rootstock for fulfillment
- Co-op billing details must flow to Rootstock for split invoicing
- Invoice numbers and PDF links must be accessible in Salesforce

**Critical Requirements:**
- Req #26: Co-op/Billable Reporting for Accounting (requires Rootstock invoice data)

## Target Implementation

1. **Order Sync:**
   - Platform Event `OrderSummaryCreatedEvent` triggers
   - Event subscriber calls Rootstock REST API to create order in Rootstock
   - Order data includes: line items, amounts, co-op details, customer info

2. **Invoice Retrieval:**
   - Custom scheduled job or webhook to poll Rootstock for generated invoices
   - Sync invoice metadata (number, date, amount, PDF URL) to custom Invoice object
   - Link Invoice records to OrderSummary

3. **Invoice Display:**
   - Custom LWC on Order Detail page to display and download invoices
   - Shows invoice number, date, amount, link to PDF

## Gaps & Risks

**Gap REI-G1: Rootstock API Documentation**
- Severity: High
- Description: API contract unknown; may lack some fields
- Impact: Integration design blocked until API reviewed
- Resolution: Validate Rootstock API documentation and capabilities
- Effort: TBD (depends on API complexity)

**Gap REI-G2: Order-to-Rootstock Data Mapping**
- Severity: High
- Description: All order fields must map correctly to Rootstock schema
- Impact: Orders could have incorrect data in ERP
- Resolution: Document full field mapping
- Effort: M (data mapping work)

**Gap REI-G3: Invoice PDF Link Handling**
- Severity: Medium
- Description: Rootstock generates PDFs; must be accessible from Salesforce
- Impact: Without PDF access, invoicing workflow is incomplete
- Resolution: Rootstock provides PDF URLs or Salesforce retrieves via API
- Effort: Bundled with REI-G1

## Dependencies

- [[order-data-model|Order Data Model]] (Order/OrderSummary objects)
- Rootstock API (external system)
- Platform Events or scheduled jobs
